把 Markdown 一键发布
到多个内容平台

md-publish 是一款基于 Electron 的跨平台桌面客户端。在本地用普通 .md 文件写作、实时预览，一键发布为草稿。

下载客户端 ☆ 查看源码

为写作者打造的发布工具

写作、预览、发布闭环，文档始终以纯文本保存在你自己的文件夹里。

📁

本地工作区

正文即普通 .md 文件；文件外部变更自动同步。

✍️

所见即所得编辑

CodeMirror 6 编辑器，语法高亮、快捷键、滚动同步一应俱全。

👁️

实时预览

markdown-it + highlight.js，GitHub 风格排版，图片按文档目录解析。

🚀

一键发布

内嵌登录窗口复用各平台登录态，默认保存为草稿，发布前可再确认。

🖼️

图片自动上传

本地图片按平台要求上传至对应图床，并替换为可用链接。

🗂️

发布记录

基于 SQLite 持久化每次发布结果，随时回溯发布历史。
