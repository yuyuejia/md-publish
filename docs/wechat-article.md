# 别再复制粘贴了：把 Markdown 一键发遍公众号、掘金、知乎、头条

## 一个写作者的真实痛点

如果你习惯用 Markdown 写作，一定经历过这样的循环：

在编辑器里写完一篇文章，然后——

发公众号，要重新排版，标题、引用、代码块格式全乱，图片还得一张张重新上传；

发掘金，复制一遍，改标题、补封面；

发知乎，再复制一遍，公式和图片又要重新处理；

发头条，再来一次……

同一篇文章，在四个平台之间被反复搬运，真正写作的时间还没有排版的时间多。更糟的是，每次搬运都可能丢格式、丢图片，最后还要挨个后台检查。

有没有一种可能：**我只写一次 `.md`，剩下的交给工具？**

## md-publish：为写作者打造的发布客户端

md-publish 是一款基于 Electron 的跨平台桌面客户端（macOS / Windows），把你本地的 Markdown 文档一键发布到多个内容平台。

在本地用普通 `.md` 文件写作、实时预览，一键发布为草稿——写作、预览、发布形成闭环，文档始终以纯文本保存在你自己的文件夹里。

![md-publish 主界面：左侧文档列表，中间 Markdown 编辑器，右侧实时预览](screenshot.png)

## 它能做什么

### 本地工作区，文件属于你自己

正文就是普通的 `.md` 文件，可以用 Git 管理，可以用任何编辑器打开。文件在外部被修改后，客户端会自动同步。

### 编辑器 + 实时预览

内置编辑器，语法高亮、快捷键、滚动同步一应俱全；右侧是 markdown-it + highlight.js 渲染的 GitHub 风格预览，图片按当前文档所在目录解析，所见即所得。

### 一键发布，默认存草稿

通过内嵌登录窗口复用各平台登录态，不碰你的账号密码。发布默认保存为草稿，最后一步的“发布/群发”由你在平台后台亲手确认，安全可控。

### 图片自动上传

本地图片会按各平台要求自动上传到对应图床，并替换为可用的外链，再也不用一张张手动传。

### 发布记录可回溯

记录每一次发布结果，什么时候发到哪个平台、结果如何，一目了然。

## 支持哪些平台

| 平台 | 说明 |
| --- | --- |
| 微信公众号 | 正文自动内联样式，默认创建草稿，群发前人工确认 |
| 稀土掘金 | 默认存草稿，可切换为直接发布 |
| 知乎 | 发布至知乎专栏（实验性） |
| 今日头条 | 默认保存草稿，图片上传头条图床 |
| 开源中国 | 默认保存草稿，正文以 Markdown 提交，图片上传开源中国图床 |

每个平台使用独立的登录态存储，互不干扰。其他平台也在陆续支持中。

## 技术细节（给爱折腾的你）

md-publish 完全开源，基于 Electron + React + TypeScript 构建：

- Electron + electron-vite + Vite
- React 19 + TypeScript + TailwindCSS
- CodeMirror 6 / markdown-it / highlight.js
- better-sqlite3（跨平台预编译，无需 electron-rebuild）

代码托管在 GitHub：https://github.com/yuyuejia/md-publish
